About

Web Assistとは

Web Assistは、中小企業・店舗・個人事業者向けのホームページ制作・改善支援サービスです。

現在のホームページや事業内容を確認し、必要な改善点を整理したうえで、サイト構成・必要機能・費用をご提案します。

不要な機能や過剰な制作を勧めるのではなく、事業目的と予算に合った現実的なホームページを構築します。

無料Web診断 現状分析 改善提案 ホームページ制作 リニューアル 公開支援 更新・保守 継続的な運用相談

Reasons

Web Assistが選ばれる理由

01

必要な改善内容と費用が分かる

ホームページの課題を整理し、何を改善すべきか、どの程度の費用が必要かを分かりやすくご案内します。

02

AIによる分析を、人が最終確認

AIを活用して分析や整理を効率化しますが、診断結果や提案内容は担当者が確認したうえでご案内します。

03

必要以上の機能を勧めない

目的や予算に合わない高額な機能や、不要な構成を無理に提案しません。

04

小さな構成から始められる

必要最低限の構成から制作を始め、事業の成長に合わせてページや機能を追加できます。

05

公開後も相談できる

ホームページ公開後の修正・更新・保守・運用についても継続して相談できます。

FAQ

よくある質問

ホームページがなくても申し込めますか？

可能です。事業内容や目的を確認し、必要なページ構成や機能をご提案します。

無料診断後に契約する必要はありますか？

無料診断や見積をご利用いただいたことによる契約義務はありません。内容をご確認いただいたうえで、正式にお申込みいただいた場合のみ契約となります。

文章や写真がなくても依頼できますか？

可能です。ヒアリング内容をもとに文章構成を支援します。写真や動画についても、現在お持ちの素材を確認しながら対応方法をご案内します。

公開後の更新も依頼できますか？

可能です。修正・更新・保守・運用を支援する月額プランをご用意しています。

制作期間はどのくらいですか？

ページ数・機能・素材の準備状況により異なります。正式なお見積り時に、制作期間の目安をご案内します。

予算が限られている場合でも依頼できますか？

可能です。55,000円のStarterプランをご用意しています。必要最低限の構成から始め、事業の状況に合わせて後からページや機能を追加することもできます。診断時に予算を確認し、無理のない構成をご提案します。

まずは、今のホームページの状態を整理しませんか？

改善すべき点があるのか、新しく作り直すべきなのか。まずは無料Web診断で、現在の状態と必要な改善内容を分かりやすく整理します。
